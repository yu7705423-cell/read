# 喵喵书阁 (meow-reader)

一个纯前端、单文件 HTML 的"伪阅读器"应用，用来存放 AIRP（AI角色扮演）过程中 user 和 char 之间产生的番外剧情、长篇小说，并附带一些配套工具（搜索、文件解析导入、语音朗读、AI总结前文）。

- **无后端**，所有数据存在浏览器的 IndexedDB 里
- **无构建流程**，纯 vanilla JS + 原生 HTML/CSS
- 通过 GitHub Pages 直接访问使用
