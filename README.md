# 喵喵书阁 (meow-reader)

一个纯前端、单文件 HTML 的"伪阅读器"应用，用来存放 AIRP（AI角色扮演）过程中 user 和 char 之间产生的番外剧情、长篇小说，并附带一些配套工具（搜索、文件解析导入、语音朗读、AI总结前文）。

- **无后端**，所有数据存在浏览器的 IndexedDB 里
- **无构建流程**，纯 vanilla JS + 原生 HTML/CSS
- 通过 GitHub Pages 直接访问使用

## 项目状态

已按「阅读器 / 故事管理系统需求规格 V1」实现。详见 [HANDOFF.md](HANDOFF.md)。

**数据模型**：角色 / 指令(系列) / 故事 / 篇章 四层，只靠 id 关联。同一个指令可以被多个角色使用，各自产出的故事完全独立。旧数据自动无损迁移（v1 的 `books` 保留不删）。

**导航**：按角色 / 按指令 / 全部故事 / HTML夹 四种视图。

**阅读**：
- 六种翻页样式，跟手滑动 / 鼠标拖拽 / 点击左右 / 键盘方向键，底部页码条可关
- 真沉浸式全屏（收起后不留任何可见 UI），阅读位置自动记录与恢复
- 滚动严格限制在正文区，不会带动整页
- 背景图上可调正文上下 / 左右 / 字号，阅读辅助线（横线本 / 虚线本 / 方格）
- HTML 作品在各自的沙箱 iframe 中运行，互不污染

**朗读**：
- 多 TTS 预设，内置 MiniMax / OpenAI / ElevenLabs / 硅基流动 快捷配置，可拉取音色
- 角色声音绑定（跟着角色走，跨故事复用），旁白支持 TTS / 系统语音 / 不朗读
- 自动识别旁白与角色对白；可选 AI 标注，失败一律自动退回规则识别
- 长按段落可只读该段或从该段开始，支持暂停 / 继续 / 停止

**AI 辅助**：前文总结、文本标注，均可拉取模型列表、测试连接、编辑提示词。

已知不做：RAR 解压（纯前端没有可靠方案）、音乐播放（规格中该章节缺失，已确认不做）。
